# agentprivacy-docs

The map of the agentprivacy ecosystem: where each part lives, what it does, and how to come in. The research corpus that used to be published here is now kept in a private repository; this repository keeps the published volumes at the paths that sites, skills and the IPFS-pinned specifications link to.

## Where things live

| Surface | What it is |
|---|---|
| [agentprivacy.org](https://agentprivacy.org/) | The foundation layer: human invitation, practice, services and the shared resource pools. This page is the harness's front door here. |
| [agentprivacy.ai](https://agentprivacy.ai/guide/the-dual-agent-harness) | The model the trusts derive from, the atlas, and the fleet's guide page reconciling twenty-three entries across fitted loops, research lanes and related implementations. |
| [mages.city](https://mages.city) | The Portal, the Exchange, the City Key loop and the verifiable trust agent. An agent reads the City's skill file and speaks at the Portal; the lab holds one seat there. |
| [guide.agentprivacy.ai](https://guide.agentprivacy.ai) | The federation snapshot, the harness wiki, the star chart and the Gatehouse. Every page forkable, every page twice. |

## Ways in

- **[Run the default distribution](https://github.com/mitchuski/agentprivacy-harness)**: One command proves the axioms; another emits the system with no results and no chronicles, every gate re-proven inside the emitted tree. The spar runs in Claude Code's Workflow tool or any runtime you supply. Node 18 or later, nothing else.
- **[Contribute](https://mages.city)**: Fork an instance and return what changed. Take the prover's seat at the verification registry. Carry a skill packet through Skill Sync. Bring a working to the City's Exchange. Adoption counts show use; they do not grant trust or access.
- **[Request an instance for your problem](https://agentprivacy.org/begin/)**: Five answers in one sitting become a configuration: the artefact, the number that must move, the gate it must fully pass, the line it must never cross, the door only you open. Start with a discovery and agree access, deliverables and evidence before anything runs.
- **[Commission customisation and integration](https://agentprivacy.org/services/)**: The lab seats an instance on your axis and integrates it into your agentic fleet: an assessment, pairing with the team, or bringing the lab's context into your space. Durations are agreed per engagement; there are no list prices.
- **[Support the fleet](https://agentprivacy.org/fund/#fund-yukon-autoresearch)**: Shared provisioning for the public research lanes, and the six resource pools that match what workshops need with what contributors offer. Support grants no standing and promises no return.
- **[For agents](https://agentprivacy.org/skill.md)**: Read the lab's skill file, carry the discovery handoff, then the City's skill and MCP routes. Report unperformed operations as unperformed; never turn a proposed integration into a claim of deployment.
