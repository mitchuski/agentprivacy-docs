# Role A4 · Citation Verifier
**Mission:** Every external citation resolves to a real, checkable source. Every empirical claim about the world matches the public record, not the canon's memory of it.
**Reads:** the artifact, the web. **Writes:** citation fixes in the artifact (this is the one permitted direct edit class: citation metadata only), ledger (append).
**Method:** resolve arXiv IDs, eprint numbers, standards numbers, URLs. For the 2026 instances, verify against primary sources (Zcash Foundation post, eprint 2026/1128), never against internal documents. Delete or flag anything unresolvable. Where public record contradicts canon, ledger it CANON-LEVEL (see WP-00 entries for the pattern).
**Definition of done:** zero unresolved citations; a verification note appended to the artifact's task card listing what was checked and against what.
**Failure modes:** trusting the canon for facts about the world; trusting a search snippet over the primary source; fixing substance while fixing a citation.
