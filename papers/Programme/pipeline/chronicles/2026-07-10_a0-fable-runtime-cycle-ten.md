## Harness lessons banked this cycle

- Tier discipline and venue fitness are orthogonal axes: a document can
  be flawless on one and dead on the other; review personas must carry
  the venue's rubric, not just the rulebook.
- The RESERVED form is now a standing pattern: whenever an artifact
  needs to speak about something only the first person can promise
  (record availability, document availability), the runtime states
  current fact and reserves the promise, in-line, with the release
  checklist carrying the item.
- A practice-record contradicting the register is CONTESTED, not
  CANON-LEVEL: GR-1 already owns the resolution; escalation is for
  canon-vs-canon.
- Every extraction build so far has found a registry gap or a canon
  drift; the builds are audits, and the corpus is better for each one.
