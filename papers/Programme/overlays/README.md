# The Overlay Layer · poetic threads across the formal corpus

**Charter, 2026-07-11 (first-person directed).** The pipeline's GR-4 rule
strips canon vocabulary, ceremony language and emoji from every formal
artifact — deliberately. This layer is the sanctioned inverse: it reads
the SAME research corpus and follows the four poetic threads the formal
register suppressed, so their casting-forward directions stay navigable.

## The four dimensions

| Code | Dimension | What it collects |
|---|---|---|
| OV-P | **Proverbs** | compressed wisdom sentences and one-line laws, each traced to the formal result it compresses |
| OV-R | **Protocols** | named protocols, procedures and rites, and what each governs |
| OV-S | **Spells & emoji strings** | seals, glyph strings and operator symbols, each decoded to its formal twin |
| OV-F | **Sci-fi concepts** | speculative forward concepts, each mapped to the formal core it dramatises and the research direction it casts |

## Structure

- `persona/` — the Loomkeeper, the role that runs this lane
- `skills/` — the three skills this runtime uses (overlay-sweep,
  thread-weaving, overlay-key-minting)
- `sweeps/` — one sweep document per dimension, evidence-anchored
- `WEAVE.md` — the relationship map: which proverb seals which protocol,
  which spell encodes which theorem, which concept casts which direction
- `keys/` — understanding cards (understanding-compression format,
  cohere-gated) whose *principles* line is the thread's proverb: the
  moving-understanding-as-key surface

## Rules of the lane

1. **Read-only over sources.** The overlay layer never edits canon, the
   pipeline, or the register. It quotes and points (file:line, GR-9
   trace-or-delete binds here exactly as in the pipeline).
2. **Poetic register sanctioned, evidence discipline retained.** Emoji,
   ceremony vocabulary and myth are WELCOME in overlay artifacts; every
   item still carries its source anchor and its formal twin.
3. **No canon minting.** New proverbs minted here are overlay artifacts
   until the first person binds them elsewhere; the Loomkeeper persona
   is a draft persona, not city cast, until ruled otherwise (GR-10).
4. **Keys close the loop.** Every woven thread ends as an understanding
   card that passes the understanding-compression cohere gate; the
   proverb is the key, the recheck is the proof it still opens the lock.
5. Overlay runs are chronicled in `pipeline/chronicles/` like any run.
